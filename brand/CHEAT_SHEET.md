## 📐 3. KÍCH THƯỚC CHUẨN MẠNG XÃ HỘI (CANVA / FIGMA PRESETS)

* **Avatar tròn (Facebook, TikTok, Zalo, YouTube):** `2048 x 2048 px` *(Dùng file `brand/assets/logo/logo-avatar-dark.svg`)*
* **Ảnh bài viết dọc (Newsfeed Facebook - Khuyên dùng):** `1080 x 1350 px` (Tỷ lệ 4:5)
* **Ảnh bài viết vuông (Facebook / Zalo):** `1080 x 1080 px` (Tỷ lệ 1:1)
* **Video & Bìa Cover (TikTok / Reels / Shorts):** `1080 x 1920 px` (Tỷ lệ 9:16 - Safe text zone cách top 220px, bottom 350px)

* **Thumbnail YouTube:** `1280 x 720 px` (Tỷ lệ 16:9)
