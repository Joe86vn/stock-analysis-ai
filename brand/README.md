# 🌟 THƯ MỤC NHẬN DIỆN THƯƠNG HIỆU VALUEX (BRAND KIT)

Thư mục này chứa toàn bộ tài nguyên, thông số kỹ thuật, quy chuẩn thiết kế, logo vector và hướng dẫn sử dụng cho thương hiệu **ValueX** trên website và các nền tảng mạng xã hội (Facebook Fanpage, TikTok, YouTube, Zalo).

---

## 🗂️ CẤU TRÚC THƯ MỤC BRAND

```
brand/
├── README.md                      # Mục lục & hướng dẫn tổng quan (File này)
├── CHEAT_SHEET.md                 # Bảng tra nhanh 1 trang (Mã màu HEX, Font chữ, Kích thước)
├── BRAND_GUIDELINES.md            # Tài liệu chuẩn hóa thương hiệu toàn diện
│
├── assets/
│   └── logo/                      # Bộ logo vector SVG chuẩn nét mọi kích thước
│       ├── logo-full-light.svg    # Logo đầy đủ cho nền sáng
│       ├── logo-full-dark.svg     # Logo đầy đủ cho nền tối
│       ├── logo-icon-light.svg    # Biểu tượng icon cho nền sáng
│       ├── logo-icon-dark.svg     # Biểu tượng icon cho nền tối
│       ├── logo-avatar-dark.svg   # Avatar vuông/tròn tối ưu Facebook, TikTok, Zalo (Nền tối)
│       ├── logo-avatar-light.svg  # Avatar vuông/tròn (Nền sáng)
│       └── logo-watermark.svg     # Logo đóng dấu bản quyền biểu đồ & tài liệu PDF
│
└── social-media/
    ├── SOCIAL_DESIGN_GUIDE.md     # Hướng dẫn bố cục, kích thước, vùng an toàn (Safe Zone)
    └── AI_PROMPTS_STOCK.md        # Bộ Prompt tạo hình ảnh phong cách tài chính bằng AI (Midjourney/DALL-E)
```
