# BỘ PROMPT TẠO ẢNH BẰNG AI (AI IMAGE PROMPT KIT)
> **Bộ câu lệnh (Prompts) mẫu chuẩn hóa nhận diện ValueX dùng cho Midjourney v6, DALL-E 3, Bing Image Creator, Flux.1, Photoshop Firefly.**

Dùng bộ prompt này để tạo background làm bìa Fanpage, video cover TikTok, hình nền báo cáo phân tích hoặc ảnh minh họa bài viết mà vẫn giữ trọn vẹn tông màu nhận diện xanh ngọc (`#10B981`) & xanh than (`#0B0F19`).

## 4. Công Thức Tự Ghép Prompt Theo Nhận Diện ValueX (Custom Prompt Formula)

Khi cần tự viết prompt mới, hãy luôn lồng các từ khóa thương hiệu sau vào câu lệnh:

```
[Chủ thể nội dung] + [Tông màu: "deep midnight navy (#0B0F19) and luminous emerald green (#10B981) accents"] + [Phong cách: "minimalist luxury fintech, clean glassmorphism, corporate elegance"] + [Ánh sáng: "cinematic soft glow, volumetric lighting"] + [Thông số: "--ar [Tỷ lệ] --v 6.0"]
```
